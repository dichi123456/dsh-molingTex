# dsh-plugin-moling-latex

**墨灵 LaTeX 的 DSH 插件**：在 DSH 右侧栏打开墨灵TeX 工作台 —— 目录树 · 编辑 · **LaTeX 自动补全** · 编译 · 日志 · PDF 预览 · SyncTeX 双向定位 · **21 个内置模板**；另带 5 个 Agent 工具，让模型直接编译论文、读报错、定位源码行。

## 安装

### DSH 界面安装

设置 → 插件 → 右上「添加插件」，输入框填：

```
github:dichi123456/dsh-molingTex
```

输入框支持 **包名 / GitHub 仓库地址 / 本地目录路径** 三种；GitHub 源装的是 `main` 最新提交。

### 指定版本（Release 安装包）

```
plugin_manager install_bundle  https://github.com/dichi123456/dsh-molingTex/releases/download/v0.8.6/dsh-plugin-moling-latex-0.8.6.tgz
```

### 本地目录

```
plugin_manager install_bundle  <本仓库本地路径>
```

- 装完**重开 DSH**（宿主半侧要加载）；
- 需要本机 TeX 发行版（TeX Live / MiKTeX）；PDF 预览与双向定位用 TeX 自带的 poppler `pdftoppm` 与 `synctex`；
- 已装同版本会返回 `already-installed`：先 `remove_bundle` 再 `install_bundle`；
- 发布页：<https://github.com/dichi123456/dsh-molingTex/releases>

## 能做什么

**启动页**：标题区左侧带**墨灵 logo**（内联 SVG，跟桌面版同款：深蓝圆角方块 + 蓝紫渐变描边 + 白色 M 折线），右边是大标题与副标题；下面先看「最近」—— 工作区与文件分两组、各最多 5 条，点一个才进工作台；不自动打开任何项目。

**模板库**：启动页「模板」区**只放一个入口**（`浏览模板库`），点开是**二级弹窗** —— 左边分类导航（全部模板 / 中文论文 / 英文论文 / 简历 / 幻灯片 / 报告），右边搜索框（名称/描述/引擎都参与匹配）+ 卡片网格，共 21 个内置模板（中文/英文论文、IEEE、Elsevier、Wiley、国赛论文、简历、Beamer 幻灯片、实验报告）。新建空白文档走启动页「启动」区的 `新建文档`（Ctrl+N）。

点一张卡进入**第二步「新建文件」**：显示选中的模板与它的引擎/文件数，`选择文件夹…` 调系统目录选择器**让你自己挑存放位置**（会先把该目录登记进白名单，再允许落地），选好点 `创建` 才真正写盘。`返回` 回列表，`Esc` 逐级退出，点遮罩关闭。

弹窗**尺寸固定**（`min(620px, 88%)` 高），切分类、换搜索词、进出第二步都不会变大变小；模板多的时候只有卡片网格内部滚动，左边的分类导航和底部的「新建中文文档」入口始终在位。

- 主文件统一叫 `main.tex`；`.cls` / `.sty` / `.bib` / `.bst` 与图片按原始相对路径逐字节写出（国赛模板的 `figures/`、Elsevier 的 `figs/` 都在）；
- 目标目录里已经有 `main.tex` 时**改落到 `<模板id>[-n]/` 子目录**，绝不覆盖已有项目；
- 编译引擎跟着模板走（中文/幻灯片/简历 → `xelatex`，英文期刊/会议 → `pdflatex`），省得手点；
- 模板素材由宿主半侧从 `lib/templates/` 读盘下发，不进浏览器包（否则首屏要多背 1.1 MB）；清单端点只回元数据。
- 模板与桌面版墨灵TeX 同源，改模板后在本仓库跑 `node tools/sync-templates.mjs` 重新同步。

**工作台**

- 左侧 **CodeMirror 6** 编辑器：LaTeX 语法高亮（One Dark 配色）、行号（窄列，省地方）、软换行、多标签；`F5` 编译、`Ctrl+S` 保存、`Ctrl+F` 搜索；
- **LaTeX 自动补全**（边打边弹，`Ctrl+Space` 手动唤出，`Tab` / `Enter` 选中，带占位符的项按 `Tab` 逐个跳字段）：
  - `\begin{` / `\end{` → 50 个常用环境；`\begin{figure` 会顺手补 `\end{figure}` 并把光标放在中间；
  - `\` 开头 → 100+ 常用命令（`\section` / `\textbf` / `\frac` / `\includegraphics` …），带参数的项直接是完整模板；
  - `\ref{` `\eqref{` … → **当前文档里的 `\label{...}`**；`\cite{` … → 当前文档里的 `\bibitem{...}`（逗号多引用只补最后一段）；
  - `\usepackage{` / `\documentclass{` → 常用宏包与文档类（`ctexart` / `IEEEtran` / `cas-dc` …）；
  - 词表在浏览器侧（`lib/client.js`），补全弹窗配色跟随主题，不额外写死颜色；
- **进入项目文件夹自动打开主 tex**：优先「你上次在这个项目里打开过的 .tex」，其次 `main.tex`，再次唯一/根目录唯一的 .tex，最后取体积最大的那个（没有 .tex 才什么都不开）；**切到另一个项目文件夹时，上一个项目打开的 tex 标签、PDF 预览与编译日志会一并关掉**（同一个项目重进不受影响）；
- **外部改动自动同步**：大模型（或任何编辑器）在磁盘上改了正在看的 tex，2 秒内自动进编辑区，**被改的行铺一层浅绿**、几秒后淡出，滚动位置不跳；标签里有未保存改动时只提醒、绝不覆盖；
- **每个对话各看各的项目**：面板状态按会话隔离 —— A 会话进了项目 A，切到 B 会话进项目 B，A 那边仍是项目 A，互不影响；切回来原样恢复（打开的标签、PDF、编译日志、文件树都在）。引擎/分栏宽度/自动保存这类**机器偏好**则共享；
- 顶栏：`首页`、工作区切换、`文件树 | 文件大纲`、`换行 | 保存 | 新建 | 自编`、连接状态胶囊、分体编译按钮（左键即编译，小三角切 快速 / 完整 / 从头）；**`保存` 是分体按钮**：左键立刻存（`Ctrl+S` 同效），小三角切 **手动保存 / 自动保存**（自动 = 停手 1.2 秒存一次）；**`自编` = 自动编译开关**：开着时保存或大模型改完文件后自动编一次（防抖，正忙不排队）；
- `文件树`：浮层文件树（**连编译辅助文件 `.aux/.toc/.out/.bbl/.log` 等也列出来**，可直接点开看），右边框可拖，**宽度随内容自适应**；进项目时抽屉不自动展开，要看再点；`文件大纲`：章节列表点一条跳一行；
- 底部状态栏：编译结果居中显示（成功绿 / 失败红），最右切换 `日志` / `PDF`。

**PDF 预览**：逐页图片，轻量不卡；清晰度 72 / 96 / 144 三档，`Ctrl+滚轮` 以鼠标为锚点缩放（0.5×–3×），`适应` 一键整页贴合当前窗口；**页面直接紧贴分割线、不留黑边**（无内边距、无底色、无投影），页与页之间只留 8px；**单击页面跳回源码行**。面板内滚动条统一收成 8px 细圆角条，tex / pdf 交界处不再是一条粗灰边。

**SyncTeX 双向定位**：编辑器右键「定位到 PDF 位置」→ 源码行跳到 PDF 对应页并画黄圈；PDF 上单击 → 跳回源码行（**文件树/提纲等浮层会自动收起，目标行闪一下绿**，不会"跳了却看不出来"）；结果显示在底部状态栏，失败也一定会说明原因。

**与对话框联动**

- **连接状态胶囊**：项目是否已在 DSH 工作区（绿 / 黄 / 灰），未连接时点一下直接加入；
- **发送选中内容**：编辑器右键「发送选中内容到对话框」，把选区以 **DSH 原生 `@` 引用 chip**（圆角方框，如 `Safety_MARL框架.tex:20`）送进当前会话输入框，不自动发送。chip 通过会话作用域的 `slash/input-insert-reference` 事件生成（不是伪造的纯文本）；造不出 chip 时自动退回一行纯文本引用，并在状态栏说明原因。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `latex_compile` | 编译 `.tex`。`quick` 单趟 draft；`full` 主编译 →（需要时）bibtex → 再编译 → 视 Rerun 提示补一趟；`clean` 先清辅助文件再走 full |
| `latex_status` | TeX Live / MiKTeX 探测：bin 目录、版本、六个引擎路径 |
| `latex_synctex` | SyncTeX 双向同步：源码行 → PDF 坐标；PDF 坐标 → 源码行 |
| `latex_clean` | 删除 `.aux/.log/.toc/.out/.bbl/.synctex.gz/...`（不碰 `.tex/.pdf/.bib`） |
| `latex_outline` | 章节标题与行号、`\input`/`\include` 依赖、`\label`/`\cite` 计数 |

引擎缺省 `auto`：`ctex`/中文 → `xelatex`；`IEEEtran`/`elsarticle`/`article` → `pdflatex`。

## 排错

| 现象 | 处理 |
| --- | --- |
| 右侧栏没有「墨灵 LaTeX」入口 | 插件没挂载：`plugin_manager list_bundles` 看有没有 `dsh-plugin-moling-latex`，没有就重装 |
| 面板状态灯是红的 | 数据通道异常：确认 `GET /moling/api/ping` 能返回 `{"ok":true,...}`，否则是宿主半侧没装载 |
| 打开文件夹后列表是空的 | 列表区会写原因：`不在允许范围内` → 用启动页「打开文件夹…」重开一次；`另有 N 个其它文件` → 该目录确实没有支持的类型 |
| 编译报「找不到引擎」 | 让 Agent 跑 `latex_status`，或在插件配置里指 `texlivePath` |
| PDF 预览空白 | 先看底部状态条：写「降分辨率预览不可用」= 取图失败（已退回内置阅读器）；两样都空就用 `latex_compile` 重新编译一次 |
| 改了代码后面板没变化 | 只改 `lib/client.js` 刷新页面即可；改 `lib/server.js` / `lib/index.js` 要**重开 DSH** |
